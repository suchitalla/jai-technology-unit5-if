# Java If Statements Unit Test Review

A standalone interactive practice quiz based on:
- `If Statements Upd.pptx`
- `IfStatementEx.java`
- The question-section style of `9 - Java Unit Test Review.html`

## Run locally
Open `index.html` in a modern browser. No installation, server, or database is required.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `java-if-statements-review`).
2. Upload `index.html` to the repository root and commit the change.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. The Pages panel will show the public URL.

## Features
- Interactive True/False, multiple-choice, matching, and fill-in questions.
- Java code tracing and login-program scenarios.
- Explanations after submission, including why incorrect answers are incorrect.
- Progress saved in the browser's local storage on that device.
- Downloadable HTML report and print / Save as PDF.
- No external libraries or backend required.

Progress is stored locally in the browser. To keep a report permanently or share it, use **Download report** after submitting.
